# UI Change Log

## Overview
This update elevates SpidyCode from a functional app shell into a more polished, premium product experience with a stronger visual system, motion language, and consistent page treatment across the app.

## What changed
- Introduced a reusable animated background and richer motion primitives for the app shell.
- Refreshed the landing experience and auth experience with stronger glass surfaces and improved hierarchy.
- Applied a premium dashboard shell, page hero system, and polished cards to the main product surfaces.
- Improved the profile, resume, settings, recruiter, community, leaderboard, and project submission experiences.
- Tightened supporting UI components such as analytics, notifications, empty states, feedback, and theme toggling.
